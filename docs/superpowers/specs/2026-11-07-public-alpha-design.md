# Подготовка Були к публичной альфе

Пользователь согласовал подготовку проекта к GitHub и поста для Пикабу.
Для кода и собственных материалов выбрана MIT. Основная версия — app_frames.

## Результат

Один воспроизводимый способ запуска, тесты без ключей и сетевых запросов,
упаковка для Windows, документация и отдельная папка исходников для публикации.
Старые версии, .env, память, ключи и журналы остаются локально.

## Изменения

- Маскировать всё текстовое описание вложения: имя, путь, сообщения об ошибках,
  содержимое, а также подписи картинок в истории. Бинарные изображения не
  маскировать и явно сообщать пользователю о передаче изображения серверу.
- Перед сетевым вызовом дополнительно фильтровать текст сообщений, включая
  системную память и результаты инструментов. Не изменять байты изображений.
- Создать автономные регрессионные тесты с подменой Electron и сетевого ответа.
  Реальные облачные проверки сделать отдельным явно включаемым сценарием,
  использующим временную память и актуальный объект Brain.
- Обновить Electron до версии, полученной из npm, вынести его в devDependencies.
  Добавить electron-builder и явный список файлов, входящих в приложение.
- Описать установку, ограничения, данные, лицензию, ручную проверку чистой Windows.
- Добавить CI для Windows: npm ci, автономные тесты, сборка, артефакт для скачивания.
- Экспортировать исходники по разрешённому списку и проверить отсутствие
  локальных данных. Экспорт не публикует GitHub-репозиторий и не отправляет пост.

## Критерии

Регрессионный тест показывает утечку до исправления и проходит после него.
npm test возвращает ненулевой код при ошибке и не использует .env, AppData или сеть.
Зависимости соответствуют lockfile. Архив исходников и состав сборки проверены.
Результаты запуска Electron и проверки на чистой Windows указываются отдельно:
успех тестов с подменой Electron не равен проверке настоящего окна.
