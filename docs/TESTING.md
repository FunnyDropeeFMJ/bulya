# Проверки

## Автономные тесты

```powershell
cd app_frames
npm ci
npm test
npm run check
```

Проверяются маскирование и восстановление данных, метаданные вложений, подписи
картинок в истории, фактическое тело запроса Chat, текст системной памяти,
цепочка tool calling, офлайн-режим, запреты чтения секретных файлов и прямых
внутренних URL, сохранение памяти и напоминаний, восстановление после повреждения,
отказ сохранять незашифрованный API-ключ.
Также проверяются привязка сохранённого ключа к серверу и создание/чтение Word
и Excel настоящими библиотеками, включая Excel conditional formatting.

Для исправления известных уязвимостей в package.json заданы точечные overrides:
uuid для ExcelJS и minimatch для сборщика. При обновлении родительских пакетов
проверяйте, нужны ли эти overrides; не удаляйте их без повторного `npm audit`.

Тесты создают отдельную папку `.test-runs/core-*` и удаляют её после завершения.
Нативные API Electron подменены. Сеть подменена в месте вызова `fetch`.
Это не проверяет внешний вид, работу Win32 и доступность облачной модели.

## Явная проверка настоящего провайдера

Эта команда обращается к выбранному серверу и может расходовать API-кредиты.
Она не читает `.env` или настройки пользователя. Значения задаются для текущего
терминала; не добавляйте их в исходники и не публикуйте историю с ключом.

```powershell
$env:BULYA_LIVE_TEST = '1'
$env:BULYA_TEST_BASE_URL = 'http://localhost:11434/v1'
$env:BULYA_TEST_MODEL = 'точное-имя-вашей-модели'
# Для облачного провайдера дополнительно задайте BULYA_TEST_API_KEY.
npm run test:live
```

Проверка использует настоящий Brain и временную память. Тестирует подключение,
поддержку function calling через безопасный ping и ответ Chat без инструментов,
поэтому не открывает браузер и не управляет рабочим столом.
Без `BULYA_LIVE_TEST=1` или обязательных параметров завершается с ошибкой.

## Настоящее окно и чистая Windows

Планировщик поведения дополнительно проверяется с управляемым временем:
сон после пяти минут реального бездействия, пробуждение, приоритет задач,
ограничения прогулок, отсутствие повторов, reduced-motion и режимы активности.
Проверяются также структура общего меню и действия его пунктов.

`npm run test:native` запускает настоящий Electron в скрытых окнах с отдельной
памятью и заблокированными HTTP-запросами. Проверяет загрузку персонажа,
preload, отправку формы чата и окна настроек/окраса. Проверяет сон/пробуждение
по сообщениям об активности, блокировку/возврат, прерывание цепочки движений,
локальную помощь, заготовку напоминания и сборку настоящего нативного меню.
Результат и снимки находятся
в `app_frames/.test-runs/native/`. Он не проверяет Win32-умения и настоящий сервер.

На отдельной учётной записи или VM без личных файлов проверить:

1. Первый запуск без ключа; окно настроек и простые офлайн-команды.
2. Сохранение ключа, перезапуск, повторный вход в настройки.
3. Прозрачность, проход кликов мимо персонажа, перетаскивание и края экрана.
4. Обычный чат, вызов инструмента, обработку недоступного сервера.
5. Перетаскивание TXT/DOCX/PDF, подтверждение и отмену отправки PNG.
6. Создание нового Word/Excel, напоминание после перезапуска.
7. Выключение самостоятельных реплик, очистку разговора и памяти.
8. Два запуска одновременно, выход через трей, повторный запуск.

Этот список требует реального GUI. Успешный `npm test` его не заменяет.
