# Выпуск публичной альфы

## Подготовка

- Запустить `npm ci`, `npm test`, `npm run check` из `app_frames`.
- Проверить зависимости: `npm audit --omit=dev` и отдельно полный `npm audit`.
  Исправления выбирать осознанно; не применять `--force` вслепую.
- Собрать `npm run dist:win` и пройти список чистой Windows из TESTING.md.
- Сверить права на графику по ASSETS.md.
- Записать короткое видео на демонстрационных данных без личных окон и файлов.

## Чистые исходники

Из корня рабочего проекта:

```powershell
node scripts/export-source.cjs
```

Скрипт копирует только разрешённые файлы в новую папку `publish/bulya-source-*`.
Он не копирует .env, ключи, память, журналы, node_modules, старые версии и
диагностические test_*.js. После экспорта выполните проверку внутри новой папки:

```powershell
node scripts/check-project.cjs
```

Перед первым коммитом просмотрите список файлов. `.gitignore` защищает от
случайного добавления, но не удаляет секреты, уже попавшие в историю Git.
Если ключ был опубликован, его нужно отозвать у провайдера.

Создайте GitHub-репозиторий и отправьте **содержимое экспортированной папки**.
Личный рабочий каталог целиком загружать не нужно. CI выполнит проверки и
положит Windows EXE в артефакты workflow. Это не GitHub Release: выпуск
`v0.4.0-alpha` оформляется отдельно, после проверки скачанного приложения.
Версия пакета 0.4.0 включает новое меню и самостоятельное поведение; это ранняя альфа.

## Что написать в релизе

Ранняя альфа для Windows 10/11 x64. Есть чат, память, настольный персонаж и
повседневные команды. Для LLM нужен собственный провайдер или Ollama.
Фильтр личных данных может ошибаться; изображения не маскируются.
Сборка без цифровой подписи. Приложить ограничения, изменения, проверенные
сценарии и ссылку на PRIVACY.md. Не заявлять поддержку систем и моделей,
которые не проверялись.

## Публикация на Пикабу

Использовать черновик PIKABU_DRAFT.md. Добавить проверенную ссылку репозитория,
ссылку на конкретный релиз и реальное видео. Не называть проект первым
ИИ-питомцем: похожие решения существуют. Акцент — характер Були,
русскоязычные повседневные задачи и личный опыт разработки.
