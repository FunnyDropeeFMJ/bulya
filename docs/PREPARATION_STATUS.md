# Проверки подготовки, 7 ноября 2026

Ниже — результаты первоначальной подготовки версии 0.3.0. Следующие изменения
меню и поведения в 0.4.0 описаны в [CHANGELOG.md](CHANGELOG.md).

## Выполнено

- Основная версия app_frames подготовлена к публичной альфе.
- MIT выбрана автором; добавлены лицензия, README и описание передачи данных.
- Закрыта воспроизведённая утечка ФИО через имена и пути вложений, ошибки чтения
  и подписи картинок в истории. Текст дополнительно фильтруется перед сетевым вызовом.
- Добавлено подтверждение передачи изображений, которые не маскируются.
- Исправлено повторное использование сохранённого ключа при смене сервера.
- Electron обновлён до 45.2.3, сборщик — electron-builder 26.18.0.
- npm audit после точечных overrides uuid/minimatch: 0 известных уязвимостей
  на дату проверки. Это не гарантия отсутствия неизвестных проблем.
- 14 автономных тестов прошли; проверено создание и чтение DOCX/XLSX.
- Настоящий Electron 45.2.3 проверен в скрытых окнах с изолированными данными:
  кадры персонажа, preload, форма чата, ответ, настройки и выбор окраса.
  Сетевой ответ в этой проверке подставной.
- Проверен состав app.asar: нет локальных ключей, памяти, журналов и старых тестов.
  Семь ключевых файлов в архиве побайтно совпадают с исходниками.
- Собран `Bulya-0.3.0-windows-x64.exe` (137 218 849 байт), без цифровой подписи.
  Имя продукта и версия исполняемого файла проверены. Это подтверждает сборку,
  но не заменяет ручной запуск всех функций готового EXE.
- Экспортированы 139 файлов. В отдельной копии выполнены `npm ci --ignore-scripts`,
  `npm test` и проверка состава: все 14 тестов прошли. Проверка не зависит
  от node_modules основной рабочей папки.
- Настроен Windows CI, проверки состава и экспорт по разрешённому списку.
- Подготовлен черновик поста, без выдуманных сроков разработки и обещаний уникальности.

## Что остаётся перед публичным выпуском

1. Проверить приложение целиком на чистой Windows или отдельной учётной записи
   по TESTING.md. В частности: прозрачность поверх реальных окон, проход кликов,
   перенос между мониторами, работа настоящих Win32-команд и восстановление после сна.
2. Проверить выбранную реальную нейросеть своим ключом. Облачные запросы при
   автоматической подготовке не выполнялись.
3. Автору сверить условия сервиса генерации графики и используемые референсы.
4. Записать настоящее видео на демонстрационных данных и добавить ссылки в пост.
5. Создать GitHub-репозиторий из экспортированных исходников и вручную проверить
   скачанную сборку перед оформлением релиза. Workflow пока не выполнялся на GitHub.

Личный .env, прежние версии и пользовательская память не удалялись и не публиковались.
GitHub-репозиторий и пост на Пикабу автоматически не создавались.
